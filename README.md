# Clear Tasks for AI Agents

A minimal, self-contained task-brief generator for AI coding agents.

**[Open the task builder](https://c0ffeec0de.github.io/agentic-development-playbook/)**

Describe the outcome, choose the task type and care level, then copy the generated brief into your coding agent. Advanced options support a project-specific verification command and independent worktrees.

The brief includes:

- The requested outcome and scope.
- A risk-appropriate workflow.
- Concrete verification instructions.
- Conditions that require the agent to stop and ask.
- The evidence it must return.

## Run locally

Download `index.html` and open it in a modern browser. There are no dependencies, build steps, accounts, analytics, or network calls.

The page does not save or transmit task text. Only the theme preference is stored in the current browser.
