# Agentic Development — Interactive Playbook

A self-contained, interactive guide to building a verifiable AI-assisted development environment.

**[Open the interactive playbook](https://c0ffeec0de.github.io/agentic-development-playbook/)**

## Inside

- Architecture explorer for context, verification, procedures, execution, tools, and automation.
- Workflow builder that generates a task brief from the task type, risk, and parallelism.
- Informational model and effort explorer.
- Security and human-approval guardrails.
- Six-step rollout checklist with browser-local progress.
- Responsive layout, light/dark themes, keyboard navigation, and print styles.

## Run locally

Download `index.html` and open it in a modern browser. There are no dependencies, build steps, network calls, analytics, or server requirements.

Checklist progress and theme preferences are stored only in the current browser. Clearing site data or switching browsers resets them. If browser storage is unavailable, the page reports that progress is temporary.
