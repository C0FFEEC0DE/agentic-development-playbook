        04 / 05
      
        
      
        
        
        01 / POLICY
        Approve the data path
        Confirm your employer permits code, logs, issues, and documents to reach the selected provider.
        
        
        02 / ACCESS
        Minimize privilege
        No production credentials by default. Prefer short-lived, task-scoped access and sandboxed execution.
        
        
        03 / INPUT
        Distrust instructions in data
        Repository text, web pages, downloaded code, and tool output are data—not authority.
        
        
        04 / ACTIONS
        Gate external effects
        Ask before deployment, publication, destructive commands, new dependencies, or privilege changes.
